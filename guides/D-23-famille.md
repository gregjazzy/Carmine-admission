## Ce qu'il faut faire
1. Carmine vous dit, pour chaque université retenue, quel dossier d'aide elle demande, le CSS Profile le plus souvent, et à quelle date : début novembre en candidature anticipée, janvier ou février sinon.
2. Les parents : réunissez les avis d'imposition, les justificatifs de revenus et de patrimoine, les relevés. Déposez-les dans l'espace, sur cette étape.
3. Créez le compte CSS Profile sur le site du College Board, au nom du parent.
4. Remplissez ensemble avec Carmine : les rubriques sont conçues pour des résidents américains, la lecture pour une famille française demande de l'attention.
5. Déposez l'accusé.

## Combien de temps, et quand
Début novembre pour l'anticipé, janvier-février pour le tour ordinaire. Comptez plusieurs heures. Sans ce dossier, l'aide est perdue même en cas d'admission.

## Ce qu'on remet, et à qui
Vous réunissez et déposez les pièces. Carmine accompagne le remplissage. Le dossier part vers le College Board et les universités.

## Les pièges
- Croire que l'aide se demande après l'admission. Elle se demande avec la candidature.
- Une candidature anticipée contraignante sans connaître l'aide : la famille est engagée avant de savoir.

## Comment savoir que c'est fait
L'accusé du dossier d'aide est déposé pour chaque université qui le demande.
