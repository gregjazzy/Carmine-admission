## Ce que tu fais
1. Copie la trame de questions depuis le panneau, adapte-la à chaque université, transmets-la par le message aux parents.
2. Indique, par cible, si l'université pèse l'intérêt manifesté. Le Common Data Set le dit ; la fiche le porte.
3. Fais tenir le journal de contacts. Relis-le avant C-17 : c'est la matière des essais « pourquoi nous ».
4. Là où l'intérêt compte, fais envoyer le message de suite, modèle LET-SUITE-VISITE.

## Ce que tu fais faire
À l'élève : inscriptions, sessions, journal, messages de suite. Aux parents : arbitrer un déplacement seulement si l'université pèse l'intérêt.

## Calendrier réel
Mars à juin de première. Arrivée en terminale : sans objet, les sessions d'automne sont trop tardives pour peser ; on prend ce qui a été vu.

## Les pièges
- Le journal vide en août. Les essais « pourquoi nous » deviennent des brochures.
- Un déplacement vendu comme décisif. Il n'achète rien là où l'intérêt n'est pas compté.

## Mode opératoire
Deux mécanismes distincts : le concret pour les essais, et l'intérêt manifesté que certaines universités pèsent explicitement. Rappeler à l'élève de noter le nom de la personne qui répond : un essai citant une réponse précise se distingue d'un essai citant une brochure.

## Critère de clôture
Une ligne de journal par cible américaine, avec un élément concret.
