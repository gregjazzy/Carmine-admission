## Ce que tu fais
1. Saisis la décision sur la cible : admis, refusé, report, avec la date. Les tâches d'événement se génèrent.
2. Admis contraignant : lettre de retrait LET-RETRAIT-ED à toutes les autres, sous quarante-huit heures. Efface les tâches des autres cibles en les retirant.
3. Report : la lettre d'intérêt maintenu se génère à quatorze jours ; on l'écrit mi-janvier, pas dans les jours suivant le report.
4. Refus : réarbitre le tour ordinaire, vérifie que le socle tient.
5. Note d'analyse dans le message aux parents.

## Ce que tu fais faire
À la famille : transmettre la décision le jour même. À l'élève : les retraits, s'il y a lieu.

## Calendrier réel
Mi-décembre. Réaction sous quarante-huit heures. Le tour ordinaire ferme au 1er janvier.

## Les pièges
- Une décision non saisie : rien ne se déclenche.
- Un retrait oublié.

## Mode opératoire
Lire la décision, puis réarbitrer le tour ordinaire dans la foulée. Le retrait après admission contraignante est une obligation contractuelle.

## Critère de clôture
Décision saisie, retraits envoyés s'il y a lieu, tour ordinaire réarbitré.
