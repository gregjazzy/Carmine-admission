## Ce que tu fais
1. Calcule l'écart entre le diagnostic B-04 et la médiane des cibles. Dimensionne le volume sur l'écart, jamais sur un forfait.
2. Écris le plan hebdomadaire, soixante-dix pour cent sur lecture et écriture. Dépose-le dans la tâche.
3. Programme un test complet chronométré toutes les trois semaines. Après chacun, fais remplir l'analyse d'erreurs par typologie.
4. Ajuste le plan sur l'analyse, pas sur l'impression.
5. Fais réserver la session officielle dès janvier.

## Ce que tu fais faire
À l'élève : le plan, les tests, les analyses. Aux parents : la réservation de session, tôt.

## Calendrier réel
Décembre à mars de première, quatre mois. Un élève arrivé en terminale n'a pas cette étape : la préparation se compresse dans C-05 rattrapé, sur la session d'octobre.

## Les pièges
- Le forfait décoratif. Un chiffre non tenu discrédite tous les autres.
- L'entraînement sans montre.
- Les maths comme levier. C'est faux pour un profil francophone.

## Mode opératoire
Trente heures pour cinquante à quatre-vingts points ; quatre-vingts à cent vingt heures de 1350 à 1500. Test complet toutes les trois semaines, analyse par typologie. Summit sert de banque d'entraînement : les sessions s'y lisent depuis le pilotage.

## Critère de clôture
Dernier test blanc dans la fourchette visée, session officielle réservée.
