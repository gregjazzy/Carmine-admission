## Ce qu'il faut faire
1. L'élève : début septembre, va sur ucas.com et crée ton compte, à ton nom, avec une adresse durable.
2. Demande à ton lycée le code de rattachement, le « buzzword », auprès de la personne qui gère les candidatures UCAS. Sans lui, la référence de l'établissement ne peut pas être envoyée.
3. Rattache ton compte au lycée avec ce code. Saisis tes qualifications : bac français, spécialités, notes de première.
4. Dépose dans l'espace une capture montrant le rattachement fait.
5. Les parents : les frais UCAS sont un forfait unique pour les cinq vœux.

## Combien de temps, et quand
Début septembre de terminale. Une heure, si le lycée donne le code sans délai. Le rattachement est ce qui bloque le plus souvent en octobre : le demander en septembre.

## Ce qu'on remet, et à qui
L'élève crée et rattache. Le lycée donne le code. Carmine vérifie.

## Les pièges
- Un lycée qui n'a jamais fait de candidature UCAS et n'a pas de code. Il doit s'inscrire comme centre, ça prend des jours : le savoir en septembre.
- Cinq vœux maximum, un seul Personal Statement pour les cinq. Aucune université ne voit les autres.
- Un dossier prêt dont la référence manque ne part pas.

## Comment savoir que c'est fait
Le compte est rattaché au lycée, les qualifications sont saisies, la capture est déposée.
