For September 2027 entry, everything happens between autumn and spring.

The dates

January 15, 2027: application.

January 31: financial aid application.

February 1: test scores received, if sent.

March 10: decisions, financial aid included.

April 10: families reply.

After January 15, applications are considered only after March 10, if space remains, and aid is then very limited.

A file ready in January

I schedule the interview, essays and any SSAT so everything is ready before January 15.
